# 🦋 Pokédex — Região de Kalos

Uma Pokédex interativa dedicada à **Região de Kalos**, apresentada nos jogos *Pokémon X* e *Pokémon Y*.

## 📖 Sobre o projeto

Este projeto foi desenvolvido para apresentar informações sobre os Pokémon encontrados na região de Kalos de uma forma simples, organizada e visualmente agradável.

A Pokédex permite consultar diferentes Pokémon e conhecer detalhes como:

- 🔢 Número na Pokédex
- 🏷️ Nome
- ⚡ Tipos
- 📊 Informações básicas
- 🖼️ Imagens dos Pokémon
- 🌿 Região de Kalos

## 🎮 Objetivo

O objetivo do projeto é praticar conceitos de **desenvolvimento web**, criando uma página temática inspirada no universo Pokémon e, ao mesmo tempo, desenvolver habilidades com HTML, CSS e JavaScript.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## 🌟 Destaques

- Interface inspirada em uma Pokédex
- Organização dos Pokémon por número
- Visual temático baseado na região de Kalos
- Navegação simples e intuitiva
- Layout desenvolvido para facilitar a consulta das informações

## 📍 Região de Kalos

A região de **Kalos** é inspirada na França e possui Pokémon introduzidos na sexta geração da franquia. Entre seus principais locais estão **Lumiose City, Santalune City, Coumarine City e Snowbelle City**.
